Load the documentation evaluation skills:

    almanac show writing-docs-eval
    almanac show writing-sentence-level

Apply the IBM DQTI characteristics and Diataxis type discipline from
writing-docs-eval. Then apply Orwell's rules and clarity diagnostics
from writing-sentence-level.

Check that documentation:
- Uses the correct Diataxis type (tutorial, how-to, reference, explanation)
- Is accurate to the current code (not stale or aspirational)
- Follows the project's doc conventions

Pass if the docs are clear, correct, and well-typed. Fail if content is
inaccurate, mistyped (tutorial pretending to be reference), or unclear.
