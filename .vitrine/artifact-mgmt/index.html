Decisions

2026-08-12 — build start, decisions locked

Name: vitrine. Layout: .vitrine// (fixed ../../ depth to .tisket/.zettel). Serving: per-repo vitrine serve (daemon later). CLI: new, sync, serve, resolve, extract, render, docs. Response inbox: POST /respond/ → responses/ + latest.json; deterministic-stamp env knob for tests.
